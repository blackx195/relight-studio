RELIGHT STUDIO

從一盞光，到一整個系列。

  1. 連接 Magnific。透過官方 OAuth 登入，授權僅供此分頁使用；無須 API Key。
  2. 加入原圖。每批最多 100 張，原始檔會在產圖時上傳 Magnific。
  3. 設定 1–4 盞燈。拖曳 3D 預覽或輸入角度；整批固定使用按下開始時的數值。
  4. 批量產圖與去背。每張先 Relight，再去背；失敗的項目可繼續，其他圖片仍會完成。
  5. 排版與下載。底圖決定畫布比例；圖片超過格數時自動增加列數。隨機排列只改順序。

圖片上的 ↻ 使用該圖上次的打光設定，從原圖重產並重新去背。排版中的示範素材沒有經過 AI 打光。

工作區自動保存在此瀏覽器。換裝置前請下載「專案」，其中包含原圖、結果與設定，但不包含登入憑證。瀏覽器儲存仍可能被清除。
